# 模型同端点安全重试

日期：2026-08-05

## 变更

- 为 Eino ChatModel 增加统一的薄重试包装，Leader、Query、Monitor 等 Agent 共用相同策略。
- 仅在模型尚未返回任何输出时，对瞬时网络错误、HTTP 408、429 和可恢复 5xx 在同一端点重试一次。
- HTTP 400、401、501、505、能力不匹配及用户取消不会重试。
- 流一旦成功建立，后续读取错误不会自动重放请求，避免重复生成工具调用或外部副作用。
- 第二次请求失败后直接返回原端点错误，不形成循环重试，也不回退到其他模型。
- 重试退避响应 Context 取消；用户停止运行时不会被重试等待拖延。
- 包装器透传底层 Eino 组件类型，Callback 和 Trace 的模型组件归因保持不变。

## 验证

- 覆盖 408、429、503、瞬时网络错误、400、401、501 和取消场景。
- 验证可恢复错误总调用次数为两次，不可恢复错误仅调用一次。
- 验证流建立失败可重试一次，已建立的流仍由调用方原样消费。
